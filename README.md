# TimeBot Invader

**TimeBot Invader** is a dungeon-crawling action game where you play as a futuristic executioner sent back in time to a medieval dungeon. Fight your way through dangerous enemies and defeat the evil bosses lurking within.

## 🎮 How to Play

Go to **[Releases](../../releases)** and download the **ZIP file from the latest release**.

Extract the ZIP file and run the game executable.

**Good luck, Executioner!**
